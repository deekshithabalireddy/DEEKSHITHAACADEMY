# Deekshitha Academy

## Description

Deekshitha Academy is a modern, responsive educational website developed using HTML5, CSS3, and JavaScript. The website provides detailed information about the academy, professional courses, faculty, gallery, and contact details. It is designed with an attractive user interface, smooth navigation, and mobile-friendly layout to provide a better browsing experience for students and visitors. The website also includes SEO optimization and a Tawk.to live chat widget for improved accessibility and communication.

---

## Problem Statement

Many educational institutions need an online platform to showcase their courses, faculty, facilities, and contact information. Traditional methods of sharing information are often time-consuming and less accessible. This project aims to develop a responsive educational website that allows students and visitors to access academy information, explore available courses, and communicate with the academy easily from any device.

---

## Features of the Program

- Responsive and mobile-friendly design
- Modern and attractive user interface
- Home page with academy overview
- About Us page with mission, vision, and faculty details
- Courses page displaying professional training programs
- Gallery page showcasing academy activities
- Contact page with enquiry form
- Sticky navigation bar
- Hamburger menu for mobile devices
- Smooth scrolling effects
- Interactive buttons and hover effects
- SEO-friendly structure
- Tawk.to Live Chat integration
- Optimized images with ALT text
- Social media meta tags (Open Graph & Twitter Cards)

---

## Functional Requirements

- Users can navigate between all website pages.
- Users can view academy information and available courses.
- Users can browse gallery images.
- Users can contact the academy through the contact form.
- Users can interact using the Tawk.to live chat widget.
- The website should be responsive on desktop, tablet, and mobile devices.
- Navigation should be simple and user-friendly.
- SEO elements should improve website visibility on search engines.
